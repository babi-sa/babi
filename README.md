# بابي · babi

رابط واحد يوصّل المندوب من الخريطة إلى باب الشقة — بالصور وبلغته (عربي / English / اردو).

## الهيكل

```
t/                  القالب المشترك (لا يُعدَّل لكل عميل)
  app.css, app.js   التصميم والمنطق — أي تحسين هنا ينعكس على كل العملاء فورًا
  client-index.html غلاف صفحة العميل (يُنسخ كما هو)
  data.template.json نموذج بيانات عميل جديد
demo/               نموذج تجريبي ببيانات افتراضية
suliman/            عميل حقيقي (مثال)
new-client.ps1      أمر إنشاء عميل جديد
message.ps1         رسائل العميل: تسليم، تذكير، إيقاف، شكر (واتساب)
lock.ps1            قفل صفحة عميل لم يدفع، أو فتحها
use/                صفحة إرشاد العميل: وين يلصق رابطه
qr/                 ملصق QR للباب (طباعة): qr/?n=<name>
```

## الدفع بعد التجربة (من 2026-11-28)
العميل يطلب بدون دفع، ويستلم رابطه، ويدفع إذا عجبه.

| اليوم | الإجراء | الأمر |
|---|---|---|
| 0 | رسالة التسليم (فيها الحسابات ومهلة 3 أيام) | `.\message.ps1 ahmad "أحمد"` |
| 3 | ما دفع؟ تذكير لطيف | `.\message.ps1 ahmad "أحمد" -Kind reminder` |
| 5 | ما دفع؟ اقفل الصفحة وأرسل الإشعار | `.\lock.ps1 ahmad` ثم `.\message.ps1 ahmad "أحمد" -Kind lock` |
| عند الدفع | افتحها (إن كانت مقفلة) وأرسل الشكر | `.\lock.ps1 ahmad -Unlock` ثم `.\message.ps1 ahmad "أحمد" -Kind thanks` |

- أضف `-F` لصيغة المؤنث، و`-Paid` لرسالة تسليم بدون طلب دفع (عميل دفع مسبقًا).
- القفل لا يحذف شي: المندوب يشوف "هذه الصفحة غير متاحة حاليًا" بثلاث لغات، بدون أي بيانات للعميل، والرابط نفسه يرجع يشتغل بعد الفتح.
- بعد القفل أو الفتح: ارفع التغيير (Claude يرفعه).

## قاعدة اسم الرابط
- حروف إنجليزية صغيرة وأرقام وشرطة `-` فقط. الأمر يحوّل الحروف الكبيرة ويحذف المسافات والرموز تلقائيًا.
- خطأ إملائي واضح في الاسم (مثل `wleed` ← `waleed`): صحّحه، واذكره للمالك.
- الاسم محجوز (مجلد موجود) أو اسم نظام (`t`, `demo`, `use`, `qr`, `order`): أضف الحي أو رقمًا (`ahmad-mahdiya` أو `ahmad2`)، والمالك يأكده مع العميل.
- الاسم بالعربي: حوّله لنطق إنجليزي (`سمية` ← `somyah`).
- لا تغيّر اسم رابط عميل بعد التسليم، لأنه ملصوق في تطبيقاته.

## عميل جديد في دقيقتين

```powershell
.\new-client.ps1 ahmad
```

ثم:
1. ضع الصور الثلاث في `ahmad/images/` بأسماء `house.jpg` و`gate.jpg` و`apartment-door.jpg` (أطول ضلع 1600px، أقل من 500KB للصورة).
2. عدّل `ahmad/data.json` — كل نص له ثلاث لغات `ar` / `en` / `ur`.
3. ارفع: `git add ahmad; git commit -m "client: ahmad"; git push`

الرابط: `https://babi-sa.com/ahmad/`

بعد الرفع، رسالة التسليم للعميل (تُنسخ للحافظة):

```powershell
.\message.ps1 ahmad "أحمد"
.\message.ps1 hajar "هاجر" -F   # عميلة: صيغة المؤنث
```

الرسالة فيها رابط صفحة الإرشاد `https://babi-sa.com/use/?n=ahmad`: تشرح للعميل وين يلصق رابطه في تطبيقات التوصيل.

## ملاحظات على data.json
- `keyDirection`: `"right"` أو `"left"` — اتجاه دوران المفتاح في الرسمة المتحركة.
- `tip` و`tipSub`: اجعلهما `null` إن لم يكن هناك تنبيه للمفتاح.
- `warnings`: قائمة؛ `type` إمّا `"ok"` (افعل) أو `"no"` (لا تفعل). تحذير `no` يظهر بالثلاث لغات معًا.
- `demo: true` يُظهر شارة "نموذج تجريبي".
